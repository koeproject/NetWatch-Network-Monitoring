ก. Global macro ของ SNMPv3

เป้าหมาย: credential ของ SNMPv3 ต้องอยู่ใน DB ของ Zabbix เท่านั้น (§9) เพราะคนที่ใช้มันตอน poll คือ Zabbix server ไม่ใช่ backend ของเรา ใน git จะมีแค่ชื่อ macro ซึ่ง Zabbix server แทนค่าให้ตอน poll

ไปที่ Administration → Macros กด Add แล้วเพิ่ม (ช่อง Value มี dropdown ให้เลือก type):

MacroTypeValue
{$SNMPV3.USER}Textnetwatch-poll
{$SNMPV3.AUTH}Secret textauth passphrase (≥ 8 ตัวอักษร)
{$SNMPV3.PRIV}Secret textpriv passphrase (≥ 8 ตัวอักษร)
  • ใช้ global เพราะไซต์นี้ใช้ SNMP user ชุดเดียว ถ้ามีสวิตช์ที่ใช้รหัสต่าง ให้ตั้ง macro ชื่อเดียวกันในระดับ host ซึ่งจะ override ค่า global
  • ใช้ Secret text ไม่ใช่ Vault เพราะยังไม่มี HashiCorp/CyberArk และ Secret text จะไม่ถูกส่งกลับออกมาทาง UI หรือ API อีก

ตรวจว่าผ่าน (ผลจริง 12 ต.ค.)

  filter = @{ macro = @('{$SNMPV3.USER}','{$SNMPV3.AUTH}','{$SNMPV3.PRIV}') } } | Format-Table
# macro          type value
# -----          ---- -----
# {$SNMPV3.USER} 0    netwatch-poll
# {$SNMPV3.AUTH} 1                     <- type 1 = Secret text, ไม่มี value
# {$SNMPV3.PRIV} 1
ชื่อ macro ใน PowerShell ต้องอยู่ใน single quote ('{$SNMPV3.AUTH}') ถ้าใช้ double quote PowerShell จะแทน $SNMPV3 ด้วยตัวแปรที่ว่าง

ข้อผิดพลาดที่พบบ่อย

  • ลืมเปลี่ยน type เป็น Secret text: รหัสจะโผล่ทั้งใน UI และ API ถ้าเกิดแล้ว ให้เปลี่ยน type และเปลี่ยนรหัสใหม่ทั้งบนสวิตช์และใน macro
  • Passphrase สั้นกว่า 8 ตัว: IOS ยอมรับคำสั่ง แต่ SNMPv3 จะ auth ไม่ผ่าน
  • พิมพ์ชื่อผิด เช่น {$SNMPV3_AUTH}: poll จะไม่ผ่านโดยไม่มี error ที่บอกชัดๆ ให้ดูที่บรรทัด global macros ของ verify.py
  • ลืมรหัส: อ่านกลับไม่ได้ ต้องตั้งใหม่ ให้เก็บไว้ใน password manager ของทีม

# NetWatch helpers (Phase 2). Run inside the NetWatch repo, any subfolder.
#   nw <module> [args]      python -m <module> in a throwaway backend container (admin token)
#   engine <method> @{...}  one JSON-RPC call to the engine with the admin token -> .result
#   portal-login <user>     log in to our backend; then: portal /api/devices
#   boundary                bash ops/check-boundary.sh

function Get-NwRoot {
  $root = git rev-parse --show-toplevel 2>$null
  if (-not $root) { throw "not inside the NetWatch repo (cd into it first)" }
  return $root
}

function Get-NwEnv([string]$Key) {
  $line = Select-String -Path "$(Get-NwRoot)/backend/.env" -Pattern "^$Key=(.+)$" | Select-Object -First 1
  if (-not $line) { throw "$Key not found in backend/.env" }
  return $line.Matches[0].Groups[1].Value.Trim()
}

function nw {
  $root = Get-NwRoot
  docker compose -f "$root/backend/docker-compose.dev.yml" run --rm `
    -v "${root}/provisioning:/srv/provisioning:ro" `
    -v "${root}/templates:/srv/templates" `
    -e "ENGINE_TOKEN=$(Get-NwEnv ENGINE_TOKEN)" backend python -m @args
}

function engine([string]$Method, $Params = @{}) {
  $body = @{ jsonrpc = "2.0"; method = $Method; params = $Params; id = 1 } | ConvertTo-Json -Depth 20 -Compress
  $headers = @{ Authorization = "Bearer $(Get-NwEnv ENGINE_TOKEN)" }
  if ($Method -eq "apiinfo.version") { $headers = @{} }  # refuses an Authorization header
  $resp = Invoke-RestMethod -Method Post -Uri "$(Get-NwEnv ENGINE_URL)/api_jsonrpc.php" `
    -ContentType "application/json-rpc" -Headers $headers -Body ([Text.Encoding]::UTF8.GetBytes($body))
  if ($resp.error) { throw "${Method}: [$($resp.error.code)] $($resp.error.message) $($resp.error.data)" }
  return $resp.result
}

$script:NwPortal = $null
function portal-login([string]$Username) {
  $pw = Read-Host "password for $Username" -AsSecureString
  $plain = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($pw))
  $body = @{ username = $Username; password = $plain } | ConvertTo-Json -Compress
  Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8000/api/login" -ContentType "application/json" `
    -Body $body -SessionVariable s | Out-Null
  $script:NwPortal = $s
  "logged in as $Username"
}

function portal([string]$Path) {
  if (-not $script:NwPortal) { throw "run portal-login <user> first" }
  Invoke-RestMethod -Uri "http://127.0.0.1:8000$Path" -WebSession $script:NwPortal
}

"""Export engine templates and our hosts to YAML, so changes show up in git diff.

    nw provisioning.export                                 # ours + inventory hosts
    nw provisioning.export --upstream "Cisco IOS by SNMP"  # as shipped -> templates/upstream/

templates/upstream/ is READ ONLY after the first export: never edit, only re-export.
"""

from __future__ import annotations

import argparse
import asyncio
import re
from pathlib import Path

from app.config import get_settings
from app.zabbix.client import ZabbixClient
from provisioning.catalog import TEMPLATE_PREFIX, load_inventory

ROOT = Path(__file__).resolve().parent.parent
OURS = ROOT / "templates" / "netwatch"
UPSTREAM = ROOT / "templates" / "upstream"


def _filename(name: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", name.lower()).strip("-") + ".yaml"


def _write(path: Path, text: str) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    old = path.read_text(encoding="utf-8") if path.exists() else None
    if old == text:
        print(f"unchanged {path.relative_to(ROOT)}")
        return
    path.write_text(text, encoding="utf-8", newline="\n")
    print(f"{'updated' if old is not None else 'created'} {path.relative_to(ROOT)}")


async def main() -> None:
    parser = argparse.ArgumentParser(prog="python -m provisioning.export")
    parser.add_argument("--upstream", metavar="TEMPLATE_NAME")
    args = parser.parse_args()

    settings = get_settings()
    admin = settings.engine_token
    if not admin:
        raise SystemExit("pass the admin token: -e ENGINE_TOKEN=...")

    async with ZabbixClient(settings.engine_url) as client:
        async def export(kind: str, ids: list[str]) -> str:
            return await client.call(
                "configuration.export", {"options": {kind: ids}, "format": "yaml"}, token=admin
            )

        if args.upstream:
            found = await client.call(
                "template.get",
                {"output": ["templateid", "host"], "filter": {"host": [args.upstream]}},
                token=admin,
            )
            if not found:
                raise SystemExit(f"template {args.upstream!r} not found")
            _write(UPSTREAM / _filename(args.upstream), await export("templates", [found[0]["templateid"]]))

"""What each inventory role becomes in the engine.

Shared vocabulary with backend/app/zabbix/mapper.py:
- host tag "role" values must be keys of mapper._KIND (core, access, ap, server)
- host tag "site" becomes Device.site
- item tag "metric" is our metric name (mapper.metric_name)
"""

from __future__ import annotations

import csv
from dataclasses import dataclass
from pathlib import Path
from typing import Any

INVENTORY = Path(__file__).with_name("inventory.csv")

TEMPLATE_PREFIX = "NetWatch "
METRIC_TAG = "metric"
REACHABILITY_TAG = ("netwatch", "reachability")
SNMP_MACROS = ("{$SNMPV3.USER}", "{$SNMPV3.AUTH}", "{$SNMPV3.PRIV}")

# Engine numbering. Interface type: 1 agent, 2 SNMP.
IF_AGENT = 1
IF_SNMP = 2
# SNMP interface details on 7.0: securitylevel 2 = authPriv, authprotocol
# 1 = SHA1, privprotocol 1 = AES128. Must match the switch (step 2.5).
SNMP_DETAILS: dict[str, Any] = {
    "version": 3,
    "bulk": 1,
    "securityname": SNMP_MACROS[0],
    "securitylevel": 2,
    "authprotocol": 1,
    "authpassphrase": SNMP_MACROS[1],
    "privprotocol": 1,
    "privpassphrase": SNMP_MACROS[2],
}
# hostgroup_rights permission: 2 = read-only.
READ = 2


@dataclass(frozen=True)
class Role:
    templates: tuple[str, ...]
    interface_type: int


ROLES: dict[str, Role] = {
    "core": Role(("NetWatch Cisco IOS by SNMP",), IF_SNMP),
    "access": Role(("NetWatch Cisco IOS by SNMP",), IF_SNMP),
    # Aruba waits on decision #1 (AOS-8 vs AOS-10). Reachability only until then.
    "ap": Role(("NetWatch ICMP Ping",), IF_AGENT),
}

TENANTS: dict[str, str] = {
    "acme-hq": "ACME HQ",
    "branch-co": "Branch Co",
}


@dataclass(frozen=True)
class Device:
    technical_name: str
    display_name: str
    role: str
    tenant: str
    site: str
    address: str
    model: str
    parent: str

    @property
    def group(self) -> str:
        # The host group IS the tenancy boundary (ADR 0004): never shared by two tenants.
        return f"tenant/{self.tenant}/{self.site}"

    def interface(self) -> dict[str, Any]:
        kind = ROLES[self.role].interface_type
        iface: dict[str, Any] = {"type": kind, "main": 1, "useip": 1, "ip": self.address, "dns": ""}
        if kind == IF_SNMP:
            return {**iface, "port": "161", "details": dict(SNMP_DETAILS)}
        # ICMP needs an IP to ping; the agent interface is only its carrier.
        return {**iface, "port": "10050"}


def load_inventory(path: Path = INVENTORY) -> list[Device]:
    with path.open(newline="", encoding="utf-8") as f:
        rows = list(csv.DictReader(line for line in f if not line.startswith("#")))
    devices = [Device(**{k: (v or "").strip() for k, v in row.items()}) for row in rows]

    names = [d.technical_name for d in devices]
    errors = [f"duplicate technical_name {n}" for n in sorted({n for n in names if names.count(n) > 1})]
    for d in devices:
        if d.role not in ROLES:
            errors.append(f"{d.technical_name}: unknown role {d.role!r}")
        if d.tenant not in TENANTS:
            errors.append(f"{d.technical_name}: unknown tenant {d.tenant!r} (add it to TENANTS)")
        if d.parent and d.parent not in names:
            errors.append(f"{d.technical_name}: parent {d.parent!r} is not in the inventory")
        if not d.address or not d.site:
            errors.append(f"{d.technical_name}: address and site are required")
    if errors:
        raise SystemExit("inventory.csv:\n  " + "\n  ".join(errors))
    return devices

def _same_interface(have: dict[str, Any], want: dict[str, Any]) -> bool:
    if any(str(have[k]) != str(want[k]) for k in ("type", "ip", "port")):
        return False
    have_details = have.get("details") or {}
    if isinstance(have_details, list):  # agent interfaces come back as []
        have_details = {}
    return all(str(have_details.get(k)) == str(v) for k, v in want.get("details", {}).items())


async def ensure_hosts(
    run: Run, devices: list[Device], groups: dict[str, str], templates: dict[str, str]
) -> dict[str, str]:
    found = await run.call("host.get", {
        "output": ["hostid", "host", "name"],
        "filter": {"host": [d.technical_name for d in devices]},
        "selectHostGroups": ["groupid"],
        "selectParentTemplates": ["templateid"],
        "selectTags": ["tag", "value"],
        "selectInterfaces": ["interfaceid", "type", "main", "ip", "port", "details"],
    })
    existing = {h["host"]: h for h in found}
    ids: dict[str, str] = {}

    for d in devices:
        want = {
            "name": d.display_name,
            "groups": [{"groupid": groups[d.group]}],
            "tags": [
                {"tag": "role", "value": d.role},
                {"tag": "site", "value": d.site},
                {"tag": "model", "value": d.model},
            ],
            "templates": [{"templateid": templates[t]} for t in ROLES[d.role].templates],
        }
        iface = d.interface()
        have = existing.get(d.technical_name)

        if have is None:
            created = await run.call("host.create", {"host": d.technical_name, **want, "interfaces": [iface]})
            ids[d.technical_name] = created["hostids"][0]
            run.changed(f"host {d.technical_name} created")
            continue

        hostid = ids[d.technical_name] = have["hostid"]
        if (
            have["name"] != want["name"]
            or {g["groupid"] for g in have["hostgroups"]} != {g["groupid"] for g in want["groups"]}
            or {(t["tag"], t["value"]) for t in have["tags"]} != {(t["tag"], t["value"]) for t in want["tags"]}
            or {t["templateid"] for t in have["parentTemplates"]} != {t["templateid"] for t in want["templates"]}
        ):
            await run.call("host.update", {"hostid": hostid, **want})
            run.changed(f"host {d.technical_name} updated")

        main = next(
            (i for i in have["interfaces"] if str(i["main"]) == "1" and str(i["type"]) == str(iface["type"])),

    return ids


# -- 4. dependencies ------------------------------------------------------------
async def reachability_trigger(run: Run, hostid: str, host: str) -> dict[str, Any] | None:
    tag, value = REACHABILITY_TAG
    found = await run.call("trigger.get", {
        "hostids": [hostid],
        "output": ["triggerid", "description"],
        "tags": [{"tag": tag, "value": value, "operator": 1}],  # 1 = equals
        "selectDependencies": ["triggerid"],
    })
    if len(found) != 1:
        run.failed(f"{host}: expected 1 trigger tagged {tag}={value}, found {len(found)} (step 2.2)")
        return None
    return found[0]


async def ensure_dependencies(run: Run, devices: list[Device], host_ids: dict[str, str]) -> None:
    for d in devices:
        if not d.parent:
            continue
        child = await reachability_trigger(run, host_ids[d.technical_name], d.technical_name)
        parent = await reachability_trigger(run, host_ids[d.parent], d.parent)
        if child is None or parent is None:
            continue
        have = [t["triggerid"] for t in child["dependencies"]]
        if parent["triggerid"] in have:
            continue
        # 7.0 has no trigger.adddependencies (-32601). trigger.update replaces the
        # whole list, so keep what is there; it works on template-inherited triggers.
        deps = [{"triggerid": t} for t in [*have, parent["triggerid"]]]
        try:
            await run.call("trigger.update", {"triggerid": child["triggerid"], "dependencies": deps})
        except ZabbixAPIError as exc:
            run.failed(f"dependency {d.technical_name} -> {d.parent}: {exc}")
            continue
        run.changed(f"dependency {d.technical_name} -> {d.parent}")

        return False
    return True


async def ensure_tenant(run: Run, container: Container, tenant_id: str, groupids: list[str]) -> str:
    rights = [{"id": g, "permission": READ} for g in groupids]
    group_name = f"netwatch-{tenant_id}-readers"
    username = f"netwatch-{tenant_id}-reader"

    found = await run.call("usergroup.get", {
        "output": ["usrgrpid"], "filter": {"name": [group_name]},
        "selectHostGroupRights": ["id", "permission"],
    })
    if not found:
        usrgrpid = (await run.call("usergroup.create", {"name": group_name, "hostgroup_rights": rights}))["usrgrpids"][0]
        run.changed(f"user group {group_name}")
    else:
        usrgrpid = found[0]["usrgrpid"]
        have = {(r["id"], str(r["permission"])) for r in found[0]["hostgroup_rights"]}
        if have != {(r["id"], str(r["permission"])) for r in rights}:
            await run.call("usergroup.update", {"usrgrpid": usrgrpid, "hostgroup_rights": rights})
            run.changed(f"user group {group_name} rights")

    found = await run.call("user.get", {"output": ["userid"], "filter": {"username": [username]}})
    if found:
        userid = found[0]["userid"]
    else:
        userid = (await run.call("user.create", {
            "username": username,
            # Nobody logs in with it: the API token is the only way in.
            "passwd": secrets.token_urlsafe(24),
            "roleid": USER_ROLE_ID,
            "usrgrps": [{"usrgrpid": usrgrpid}],
        }))["userids"][0]
        run.changed(f"user {username}")

    stored = await container.store.get_tenant(tenant_id)
    if stored is not None and await _token_works(run.client, stored.engine_token):
        token = stored.engine_token
    else:
        old = await run.call("token.get", {
            "output": ["tokenid"], "userids": [userid], "filter": {"name": [TOKEN_NAME]},
        })
        if old:
            await run.call("token.delete", [t["tokenid"] for t in old])
        tokenid = (await run.call("token.create", {"name": TOKEN_NAME, "userid": userid}))["tokenids"][0]
        token = (await run.call("token.generate", [tokenid]))[0]["token"]
        run.changed(f"tenant {tenant_id}: new read token")

    if stored is None or stored.engine_token != token or stored.name != TENANTS[tenant_id]:
        await container.auth.add_tenant(Tenant(tenant_id, TENANTS[tenant_id], token))
        print(f"  tenant {tenant_id!r} saved in our store (token encrypted; not printed)")
    return token

async def adr_0004_check(run: Run, tenant_id: str, token: str, devices: list[Device]) -> bool:
    expected = {d.technical_name for d in devices if d.tenant == tenant_id}

    print(f"ADR 0004 check, tenant {tenant_id}: {'PASS' if ok else 'FAIL'}{detail}")
    return ok

provisioning/verify.py

"""Check the engine against provisioning/inventory.csv. Read-only.

    nw provisioning.verify

Per device: in the engine, SNMP interface available, no unsupported items,
items tagged "metric" exist, exactly one reachability trigger.
Also: global SNMPv3 macros exist, no stray hosts in tenant groups. Exit 1 on FAIL.
"""

from __future__ import annotations

import asyncio
from typing import Any

from app.config import get_settings
from app.zabbix.client import ZabbixClient
from provisioning.catalog import IF_SNMP, METRIC_TAG, REACHABILITY_TAG, SNMP_MACROS, load_inventory


async def main() -> int:
    settings = get_settings()
    admin = settings.engine_token
    if not admin:
        raise SystemExit("pass the admin token: -e ENGINE_TOKEN=...")
    devices = load_inventory()
    failed = 0

    async with ZabbixClient(settings.engine_url) as client:
        async def call(method: str, params: Any) -> Any:
            return await client.call(method, params, token=admin)

        macros = {m["macro"] for m in await call("usermacro.get", {"output": ["macro"], "globalmacro": True})}
        missing = sorted(set(SNMP_MACROS) - macros)
        print(f"{'global macros':<16} {'PASS' if not missing else 'FAIL missing ' + ', '.join(missing)}")
        failed += bool(missing)

        hosts = {h["host"]: h for h in await call("host.get", {
            "output": ["hostid", "host"],
            "filter": {"host": [d.technical_name for d in devices]},
            "selectInterfaces": ["type", "available", "error"],
        })}
        tag, value = REACHABILITY_TAG
        for d in devices:
            h = hosts.get(d.technical_name)
            if h is None:
                print(f"{d.technical_name:<16} FAIL not in the engine (run provision)")
                failed += 1
                continue
            problems: list[str] = []
            for i in h["interfaces"]:
                if str(i["type"]) == str(IF_SNMP) and str(i["available"]) != "1":
                    problems.append(f"SNMP interface available={i['available']} {i['error']}".rstrip())
            unsupported = await call("item.get", {
                "hostids": [h["hostid"]], "output": ["name", "error"], "filter": {"state": 1, "status": 0},
            })
            problems += [f"unsupported: {it['name']}: {it['error']}" for it in unsupported[:5]]
            if len(unsupported) > 5:
                problems.append(f"... and {len(unsupported) - 5} more unsupported")
            tagged = int(await call("item.get", {
                "hostids": [h["hostid"]], "countOutput": True,
                "tags": [{"tag": METRIC_TAG, "operator": 4}],  # 4 = exists
            }))
            if tagged == 0:
                problems.append(f"no items tagged {METRIC_TAG}: nothing will reach our store")
            reach = int(await call("trigger.get", {
                "hostids": [h["hostid"]], "countOutput": True,
                "tags": [{"tag": tag, "value": value, "operator": 1}],
            }))
            if reach != 1:
                problems.append(f"{reach} triggers tagged {tag}={value}, expected 1")
            print(f"{d.technical_name:<16} {'PASS' if not problems else 'FAIL'}  ({tagged} metric items)")
            for p in problems:
                print(f"    - {p}")
            failed += bool(problems)

        groups = await call("hostgroup.get", {"output": ["groupid"], "search": {"name": "tenant/"}, "startSearch": True})
        if groups:
            in_groups = {h["host"] for h in await call("host.get", {
                "output": ["host"], "groupids": [g["groupid"] for g in groups],
            })}
            stray = sorted(in_groups - {d.technical_name for d in devices})
            print(f"{'stray hosts':<16} {'PASS' if not stray else 'FAIL ' + ', '.join(stray)}")
            failed += bool(stray)

    print("verify: " + ("PASS" if not failed else f"FAIL ({failed})"))
    return 1 if failed else 0


if __name__ == "__main__":
    raise SystemExit(asyncio.run(main()))

Syntax ต่างกันตาม IOS version ด้านล่างนี้ใช้ได้กับ IOS 15.x และ IOS-XE 16.x/17.x

ทดสอบ dependency (ไม่ต้องดับระบบจริง)

  1. ใน UI เปิด host CORE-SW-01 แล้วเปลี่ยน IP ของ interface เป็น IP ที่ไม่มีอยู่จริง (เช่น 10.10.0.254) แล้วกด Update จากนั้นรอจนเห็น problem Unavailable by ICMP ping ของ core (ประมาณ 3 นาที: ping ทุก 1 นาที × 3 ครั้ง)
  2. ทำแบบเดียวกันกับ ACC-SW-01 แล้วรออีก 6 นาที (นานกว่า {$SNMP.TIMEOUT} 5 นาที เพื่อให้ No SNMP data collection มีโอกาส fire ด้วย)
  3. portal /api/problems | Select-Object device_ref, title (ต้อง portal-login ก่อน ตาม 2.6)
  4. คืนค่า IP ด้วย nw provisioning.provision ซึ่งจะพิมพ์ ~ host … interface updated 2 บรรทัด เพราะ provision แก้ IP กลับให้ตรงกับ CSV
ผ่านเมื่อ: ขั้นที่ 3 เห็น problem เดียว คือ Unavailable by ICMP ping ของ CORE-SW-01 ส่วน ACC-SW-01 ไม่มีทั้ง ICMP และ SNMP problem และ core เองก็ไม่มี No SNMP data collection (เพราะ depend on ICMP ของตัวเอง) หลังคืนค่า IP แล้ว problem ของ core ต้อง resolve ภายในไม่กี่นาที
ไม่ใช้วิธีลบ SNMP ACL บนสวิตช์ เพราะ reachability ยึด ICMP (ขั้น 2.2) การปิด SNMP จะทำให้ ping ยังผ่าน ICMP trigger จึงไม่ fire และทดสอบ dependency ไม่ได้ วิธีเปลี่ยน IP ในฝั่ง engine ไม่แตะอุปกรณ์จริงเลย และ provision คืนค่าให้เอง

ข้อผิดพลาดที่พบบ่อย

  • เปลี่ยน IP ของ access ก่อน core ทำให้ trigger ของ access fire ไปก่อน เพราะ dependency มีผลเฉพาะตอนที่ master อยู่ในสถานะ PROBLEM แล้วเท่านั้น
  • ลืมคืนค่า IP: nw provisioning.verify จะ FAIL ที่ SNMP interface ให้รัน nw provisioning.provision
  • เปลี่ยน technical_name ใน CSV ระหว่าง rollout จะได้ host ใหม่ และประวัติของตัวเดิมขาดหาย (ADR 0006) ถ้าจะเปลี่ยนชื่อที่แสดง ให้แก้ display_name แทน
  • AP แสดงสถานะ unknown เป็นเรื่องปกติ เพราะ interface ของ AP เป็นแค่ที่ใส่ IP สำหรับ ping จนกว่าจะปิด decision #1
